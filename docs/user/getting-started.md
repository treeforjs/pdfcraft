# Getting started

## The window

- **Menu** (top left) holds File, Edit, Pages, View and Help.
- **Workspace tabs** next to it switch what the left panel offers: **All tools**, **Read**, **Edit**, **Convert** and **E-Sign**. Read hides the tool panel so the page gets the room.
- **Find tools and commands** (top right) searches every tool by name. Press ⌘K to jump straight to it.
- **Document tabs** show each open file. A dot on a tab means it has unsaved changes.
- **The rail** on the right opens side panels: Comments, Bookmarks, Page thumbnails, Form fields, Layers, Attachments and Signatures. A small dot on a button means the document has something to show there.
- **The quick bar** floating beside the page holds the tool you are using: Select (V), Hand (H) and the tools of the group you picked.

## Home

With no document open, PdfCraft shows Home: recent files, folders you pinned (**File → Pin folder to Home…**) and suggested tools. Click a file to open it. **File → Open Recent → Clear Recent Files** empties the list.

## Opening files

- **File → Open…** (⌘O), or drag PDF files onto the window.
- A password-protected file asks for its password. If you have the owner password, enter it to lift the document's restrictions.
- Damaged files are repaired as they open when possible. PdfCraft tells you when it had to repair something.
- Very large files open quickly: pages are read as you reach them.

## Saving

- **File → Save** (⌘S) adds your changes to the end of the file. The original content stays as it was, and the file is written safely: a copy is written first and then swapped in.
- **File → Save as…** (⇧⌘S) writes a new, compact file.
- **File → Revert** goes back to the last saved version.
- Closing a document or quitting with unsaved changes always asks first.

## Undo

Every change to a document can be undone with **Edit → Undo** (⌘Z) and redone with **Edit → Redo** (⇧⌘Z). The Edit menu names the step, for example "Undo Rotate pages". Undo still works after you save.

## If PdfCraft closes unexpectedly

Unsaved changes are copied to a recovery folder every minute (you can change the interval in [Preferences](preferences.md)). The next time PdfCraft starts, it offers to recover them. **File → Recover unsaved documents…** shows them at any time. Copies of encrypted documents stay encrypted.

## Finding a tool

- Press ⌘K and type what you want to do, such as "rotate" or "watermark".
- Or open **All tools**, which lists every tool by group. Tools that are still being built carry the milestone that will bring them.
- A tool that can't be used right now (for example, because no document is open, or the document's security forbids changes) says why when you point at it.

## Getting help

- **Menu → Help → User guide** opens this guide.
- **Menu → Help → Keyboard shortcuts** (⌘/) lists every shortcut, with a search box. The **?** button at the right end of the tab bar opens it too.
- **Menu → Help → Check for updates…** looks for a newer release and, where your kind of install allows it, downloads it, checks its signature and installs it when you quit. PdfCraft also checks once a day in the background and only shows a notice; you can turn that off under General in [Preferences](preferences.md).
