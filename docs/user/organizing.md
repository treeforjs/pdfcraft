# Organizing pages

## The page grid

**Pages → Organize pages** (or **All tools → Organize pages**) shows every page as a card.

- Click a page to select it, ⌘-click to add or remove pages, and ⇧-click to select a run of pages. ⌘A selects every page.
- Drag pages to move them. Drop files from your computer onto the grid to insert their pages there.
- The size slider, or ⌘+ and ⌘−, makes the cards larger or smaller.
- Delete removes the selected pages.

Every change can be undone with ⌘Z.

## Page commands

These are in the **Pages** menu, the page grid's toolbar, and the right-click menu of the page thumbnails:

- **Rotate pages clockwise** and **counterclockwise**, or **Rotate pages…** to rotate a range, only odd or even pages, or only portrait or landscape pages.
- **Delete pages**, **Duplicate pages**, **Insert blank page**.
- **Insert pages from file…** and **Insert pages from clipboard**.
- **Cut**, **copy** and **paste** pages, also between documents.
- **Replace pages…** swaps pages for pages of another file.
- **Extract pages…** copies pages into a new document, or into one file per page, and can delete them from the original.
- **Split document…** divides a file every few pages, before chosen pages, by file size, or at each top-level bookmark.
- **Crop pages** lets you drag the area to keep. **Set page boxes…** sets the crop, trim, bleed and art boxes exactly.
- **Number pages…** sets page labels, so pages can be numbered i, ii, iii and then 1, 2, 3.

## Combining files

**File → Combine files…** puts several files into one PDF.

- Add files, then drag them into order or sort them by file name, page count, size or date modified.
- Choose which pages of each file to use.
- Each file gets a bookmark with its own bookmarks inside it.
- Links, form fields, layers and attachments keep working, and fonts and pictures that appear in several files are stored once.

## Bookmarks

Bookmarks are the document's table of contents.

- **Pages → New bookmark** (⌘B) adds a bookmark for the current view.
- In the Bookmarks panel, rename, delete, drag to reorder or nest, set where a bookmark goes, or expand and collapse them all.
- Bookmarks can also be made from the document's headings.

## Document details

**File → Document properties…** (⌘D) edits the title, author, subject and keywords, the document's language, and how it opens (layout, zoom, which panel shows, whether the window shows the title). It also lists the fonts with their type and whether they are embedded.
