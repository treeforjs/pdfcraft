# PdfCraft user guide

PdfCraft is a free, open-source PDF application for macOS, Windows, Linux, FreeBSD and the web. You can read, comment on, fill in, sign, edit, organize and protect PDF files with it. It needs no account and sends nothing anywhere: your documents stay on your computer.

This guide explains what PdfCraft can do and how to do it. It is written for people who use the app. You can read it here, or inside PdfCraft from **Menu → Help → User guide**, which works offline.

## A note on shortcuts

On macOS, shortcuts use ⌘ (Command). On Windows, Linux and FreeBSD the same shortcuts use Ctrl. This guide writes them the macOS way, for example ⌘S, which means Ctrl+S on the other systems. ⇧ is Shift and ⌃ is Control.
