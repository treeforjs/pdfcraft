# Creating, converting and printing

## Making a new PDF

From **File** or **All tools → Create a PDF**:

- **New blank PDF**.
- **Create PDF from file…**: an image or a plain text file.
- **Create PDF from images…**: JPEG, PNG, TIFF (each page of a multi-page TIFF becomes a page), GIF, BMP and JPEG 2000, with compression options.
- **Create PDF from multiple files…**: convert many files in one go.
- **Create PDF from clipboard**: whatever image or text you copied.
- **Create PDF from screen capture**, **window capture** or **region capture**.

## Exporting

**File** and **All tools → Export a PDF** turn a PDF into other formats:

- **Word** (.docx), **Excel** (.xlsx, with tables detected), **RTF**, **HTML** and **plain text**.
- **Images**: each page as PNG, JPEG or TIFF. **Export all images** saves every picture inside the document.

Exports aim to keep the layout and reading order, but complex pages may not come out exactly like the original. Scanned pages can be read with text recognition first (see [Text recognition](ocr.md)).

## Making files smaller

- **File → Reduce file size…** shrinks a file in one step, mainly by making large pictures smaller.
- **File → Optimize PDF…** gives full control: picture resolution and compression, fonts, and which extras to remove (scripts, thumbnails, tags, bookmarks, comments, form fields, metadata, attachments, hidden layers and more). Pictures are only replaced when the result is smaller.
- **Audit space usage…** shows what takes up the room in a file.

## Standards and checks

- **PDF/A…** checks or converts a document for long-term archiving.
- **Preflight…** checks a document against a profile (for print, archiving or accessibility) and can fix many problems, with a report you can save.
- **Fix hairlines** thickens lines too thin to print.

## Guided actions

**All tools → Use guided actions** runs a series of steps on one or many files: **Prepare for distribution**, **Optimize scanned documents** and **Archive documents** are built in, and **Action Wizard…** lets you make and save your own.

## Printing

**File → Print…** (⌘P) chooses the printer, copies, pages (all, current, a range or page labels), odd or even pages, reverse order, both sides, and how to fit pages to paper. It can also print several pages per sheet, booklets and posters split over many sheets, in greyscale or as an image, and with or without comments and form fields. A preview shows the result before you print.

For print shops, **All tools → Use print production** includes Preflight, Set page boxes and Fix hairlines. Output preview, colour conversion and printer marks are available to automation (see [Automation](automation.md)) and are still being added to the app.
