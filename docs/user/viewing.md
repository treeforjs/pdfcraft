# Reading and navigating

## Zoom

- ⌘+ and ⌘− zoom in and out. You can also pinch on a trackpad, or scroll while holding ⌘.
- ⌘1 shows the page at actual size, ⌘0 fits the whole page, ⌘2 fits the width and ⌘3 fits the visible content.
- **Menu → View** also offers Fit to height and **Marquee zoom**: drag a rectangle to zoom into it.
- The zoom buttons and the page number field sit at the bottom of the rail.

Deep zoom stays sharp because large pages are drawn in tiles.

## Page layouts

**Menu → View → Page display** chooses how pages are laid out:

- **Continuous scrolling**: one column of pages that scrolls smoothly.
- **Single page**: one page at a time.
- **Two-page view**: facing pages, with **Show cover page in two-page view** for books.
- **Fit to width scrolling** and **Fit one full page** set the layout and the zoom together.

You can choose the layout and zoom new documents open with in [Preferences](preferences.md). A PDF that asks for a particular layout gets it.

## Moving around

- → and ← go to the next and previous page in every layout. Home and End go to the first and last page.
- ↓ and ↑ scroll; Page Down and Page Up scroll a screen at a time.
- ⇧⌘N puts the cursor in the page number field, so you can type a page number or the document's own page label (such as "iv").
- ⌘[ and ⌘] go back and forward through the places you have been, like a browser.
- Click links to follow them. Whether links may open web sites, and whether PdfCraft asks first, is set under Security in [Preferences](preferences.md).
- Hold Space, or pick the Hand tool (H), to drag the page around.
- On Linux, click the middle mouse button to scroll automatically; move the pointer away from where you clicked to go faster.

## Rotating the view

⇧⌘+ and ⇧⌘− turn the view without changing the file. To rotate the pages themselves, see [Organizing pages](organizing.md).

## Read mode and full screen

- **Menu → View → Read mode** (⌃⌘H) hides the tools so only the document is left.
- **Menu → View → Full screen mode** (⌘L) fills the screen. Esc leaves it.

## Finding text

- **Edit → Find…** (⌘F) opens the find bar. Matches are highlighted as you type.
- ⌘G goes to the next match and ⇧⌘G to the previous one. Esc closes the bar.
- The find bar has options for whole words and matching case, and a list of all results.
- **Edit → Advanced search…** (⇧⌘F) opens a search window with more options. It can also search every PDF in a folder.

## Selecting and copying

- Drag across text to select it, double-click to select a word, and press ⌘C to copy. Text comes out in reading order, including columns, right-to-left scripts and Chinese, Japanese and Korean.
- **Edit → Take a snapshot** copies a rectangle of the page as a picture.
- Some documents don't allow copying. PdfCraft tells you when that is the case.

## Side panels

The rail on the right opens:

- **Page thumbnails**: small pictures of every page. Click one to go there; right-click for page commands.
- **Bookmarks**: the document's table of contents. Search it to find a nested entry.
- **Layers**: turn optional content on and off.
- **Attachments**: files stored inside the PDF. Open or save them. Risky file types are blocked from opening.
- **Comments**, **Form fields** and **Signatures**: see [Comments](comments.md), [Forms](forms.md) and [Signatures](signing.md).

## Tabs and windows

- Each document opens in its own tab. Scroll the tab strip when there are more tabs than fit.
- **Menu → View → New window** opens a second view of the current document in its own window.
- Drag a tab out of the tab strip to give it its own window, or onto another window's tabs to move it there. **Move tab to main window** brings it back.

## Comparing two versions

**All tools → Compare files** shows what changed between two PDFs: text changes and visual changes, a list of differences, and a side-by-side view with synchronised scrolling. You can also save a summary report as a PDF.

## Themes

The theme button at the right end of the tab bar, and **Menu → View → Display theme**, choose a theme: Light gray, Warm, Dim, Dark gray, or the system setting.

## Document properties

**File → Document properties…** (⌘D) shows the title, author, page size, fonts, security and other details, and lets you change the title, author, subject, keywords and how the document opens.
